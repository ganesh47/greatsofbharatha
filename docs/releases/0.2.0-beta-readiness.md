# 0.2.0 kids learning beta

Linked issue: [#149](https://github.com/ganesh47/greatsofbharatha/issues/149). Implementation: [PR #208](https://github.com/ganesh47/greatsofbharatha/pull/208).

The three implementation agents and lead integrated both plan milestones into the default six-chapter journey. Children can discover Shivneri details, solve offline fort clues, try one authored correct quiz choice, gently retry, place an earned keepsake, and continue to the next chapter. Matching, review cards, and the Chronicle book are available after learning. Progress, settings, assistance, and interrupted activities persist with honest evidence.

## Automated acceptance

- 52 unit/content/state tests plus five phone UI journeys passed on iPhone 17 Pro, iOS 27 simulator, Xcode 27.
- The same five UI journeys passed on iPad mini, iOS 27 simulator.
- Journeys cover connected quiz/matching/relaunch; landscape; maximum accessibility text; parent-gated settings/relaunch; and wrong-answer retry, reward, Album placement and next chapter after relaunch.
- 41 Python release fixtures passed, including exact-version matching, main-SHA gates, automatic Cloud run reuse, source linkage, internal group association, terminal errors, numeric stamping, and real ES256 fixture signing.
- SwiftLint, Ruff, actionlint, shell syntax and pinned dependency audit passed. GitHub repeats the app and security checks before merge and on the exact merged commit.
- Large text narration controls stack vertically. Narration is optional and shares one controller; child-facing map recognition records clue understanding rather than claiming geographic accuracy.

## Release verification

Target: `0.2.0`, existing `Default` Xcode Cloud workflow and existing `GoB - Internal Testing` group. Final source SHA, Cloud run number, exact App Store Connect build ID, internal availability, group membership, and GitHub gate URLs are recorded by publishing in `testflight.json`. The sanitized publishing artifact and [v0.2.0 GitHub release](https://github.com/ganesh47/greatsofbharatha/releases/tag/v0.2.0) are the authoritative publication record; a tag or GitHub release alone is not upload proof.

The repository uses native Apple frameworks and no third-party app cryptography. The app declares `ITSAppUsesNonExemptEncryption = NO` using [Apple’s native-framework guidance](https://developer.apple.com/documentation/Security/complying-with-encryption-export-regulations). CI credentials and signing stay outside the application.

## TestFlight smoke checklist

On a real device, open the intended build in TestFlight, complete Shivneri, try a wrong answer, place its keepsake, close/reopen the app, and confirm Torna is next. Toggle narration and assistance through the grown-up gate, test interrupted speech and Reduce Motion, and complete a core activity with networking disabled.

Physical-device installation, VoiceOver listening, narration quality, and child/parent comprehension sessions require human validation. Simulator checks and App Store Connect API availability do not establish those results. Keep #149 open for this field validation and longer-term enrichment.
